# 八步选品规则详细参考

本文是 SKILL.md 各步骤的细则展开，按需加载。

## 筛选规则（第 2 步 · 七套 filter）

| 规则 | 计算 | 角度 |
|---|---|---|
| A 评论门槛洼地 | 价格带 + 月销下限 + 评论数上限 + 抛重上限 | 时间成本 |
| B 差评改良位 | 月销下限 + 星级 ≤4.2 | 产品缺陷 |
| C 新品已验证 | 上架 ≤12 月 + 月销下限 + 评论数上限 | 形态验证 |
| D 近期攒评快 | 评论数 ÷ 在架天数，只对上架 ≤12 月的品算（老品会虚高） | 当下热度 |
| E 评论转化效率 | 月销售额 ÷ 评论数，卡评论数 ≥30（分母小会失真） | 评论依赖度 |
| F FBA 占售价 | fba_fee ÷ price ≤18% —— 筛的是物流不吃利润的位置 | 物流拖累 |
| J 大盘子低门槛 | 月销售额 ≥$20k 且评论数 30–500（质量最高的一条） | 盘子 × 门槛 |

- 命中分布含义：B 多 = 差评位；C/D 多 = 新品能起来；J 多 = 大盘子低门槛。
- 命中量先松后紧：>200 收紧一档、<30 放宽一档，每次只动一条并写明。

## 利润公式与判定（第 5 步）

公式（先列给用户确认再算；尺寸 cm、重量 kg、金额 USD，采购与头程运价为 CNY；抛重直接 ÷ 除数，不要再乘 16.387）：

```
计费重       = max(实重, 抛重)
头程($/件)   = 计费重 × 运价(¥/kg) ÷ 汇率
广告前毛利   = 售价 − 佣金 − FBA − (1688 采购 ÷ 汇率 + 头程)
毛利率       = 广告前毛利 ÷ 售价
保本广告占比 = 毛利率 − 退货率
广告后贡献   = 广告前毛利 − 售价 × (广告占比 + 退货率)
```

判定三档：

| 判定 | 条件 | 动作 |
|---|---|---|
| 通过 | 毛利率 ≥30% 且保本广告占比 ≥25% | 进第 6 步，回填目标售价、到岸成本上限、采购价上限、首批件数 |
| 观察 | 毛利率 20–30%，或逆风后为负 | 等真实报价再算 |
| 淘汰 | 毛利率 <20%，或顺风后为负 | 写清卡在哪项、什么条件能翻案 |

- 1688 双路货源：**以图搜图**（用对标里形态最主流那款的主图，一张不行换 2–3 张，捞到的多是跨境导向卖家）+ **类目节点**（category_tree 逐层到叶子再节点检索，捞到的多是产业带工厂、更可能接改模）。两路分两张表列，不能按销量混排。
- 默认参数（全部显著标「示例」）：头程 ¥12/计费kg、抛重除数 6000、汇率 6.70、佣金按站点类目阶梯（不一律 15%）、广告占比 20%、退货率用节点实测值、FBA 用真值。
- 逆风测试：采购 +10%、广告 30%、退货率 ×1.5。
- 一组数：一个定位用一组数 —— 售价取价格带中位数，尺寸重量取 10 个对标的中位数。
- 首批件数 = (资金上限 − 60 天广告预留 − 头程) ÷ 采购单价。广告后贡献不是净利润（未含固定管理费、税）。
- 待补红线：采购价无结果 / 报错 / 零报价都不等于零成本，标「待补」该行利润留空；相似款不是同款；不同规格不平均成一条不存在的报价。
- 全部不过线 → 改定位或换供应链，**不许调低目标利润率**。

## 供应商排序（第 8 步）

- 排序分 = √(30天销量) + 复购率×0.3 + 工厂身份加分（超级工厂 30 / 实力商家 15）+ 服务分三项之和×2。
- 十列表：厂家（可点 1688 链接）· 产地 · 报价 · 起订 · 30天销量 · 复购率 · 服务分 · 发货时效 · 是否一件代发 · 在售款。
- 候选全是 30 天销量个位数 = 这个方向没人批量做，采购价与利润结论一起降级。
- 1688 价格是否含税 / 起订价未验证，报告标来源与查询日期。

## 交付物（第 8 步）

- **内部 PRD 八节**：定位 → 卖点（标对应差评条数）→ 规格（含包装尺寸与毛重上限）→ 到岸成本上限 → 验收标准 → 合规要求 → 变体规划 → 交付节点；每节标来自哪一步。每个通过的定位各一份，不要只做一个。
- **打样检查表**：末项固定「专利核查回执，没打勾不下量产单」。
- **发工厂版规格书**：每个定位一个文件。剥离：到岸成本、售价、毛利率、保本广告占比、退货率、任何美元金额、对标 ASIN、竞品品牌名（改「市面已有品牌」）、差评条数（改「用户反馈」）；**不给目标采购价，让工厂报价**。结尾附报价要求（含税与否 · 起订量与阶梯价 · 打样费与周期 · 能否改模及费用 · 包装与外箱尺寸毛重 · 可提供的检测报告）；页脚写「本文只含规格与验收要求，不含我方成本、定价与渠道信息」。
- **交付前自检**：grep 正则 `B0[A-Z0-9]{8}` / 到岸 / 毛利 / 差评 / `\$[0-9]` 和竞品品牌名，结果必须为空。

## 交付规范

- 客户端能写文件时，最终交付一份自包含单页 HTML：每步一个 tab，tab 结构 = 角标 → 收敛型标题（如「87 个类目 → 9 白名单 → 2 推荐」）→ 口径行（站点 / 数据源 / 生成日期 / 样本）→ 结论先行 → KPI → 正文。
- 深赭 `#8c3f1c` + 墨棕 `#2a2419` 配色；**不加任何水印**；禁外链 CSS / JS / 字体；图片 base64 内嵌。
- 第 5 步利润表必须可调：全局参数 + 每行输入，改完即时重算，带「恢复默认」。
- 不能写文件时按同样结构用 Markdown 分步输出；用户明确要纯文本才降级。

## 口径红线

- 不许出现没格式的段落：`<style>` 里必须给正文 p/h3/ul/li 设字号（12.5–13.5px）、行高（≈1.75）和段间距 —— 全局 `*{margin:0}` 后裸 `<p>` 会挤成一团；「选择原因 / 推荐意见 / 受众与场景」做成带左边线的独立块；flex/grid 容器里不要直接混放文字和 `<b>`，先包一层 `<p>` 或 `<span>`。
- ASIN 表：凡出现 ASIN 的表带主图与 `https://www.amazon.com/dp/<ASIN>` 链接；第 2 步命中结果全部逐条列出，按命中条数分组，命中原因写成一段人话。
- 样本口径：TOP100 是样本不是全量，说「进榜数」不说「在售数」。单品平均效率 = 价格带销量占比 ÷ 价格带进榜数（1.00% 为基准）。
- 用词：说「细分市场」不说「格子」；拿不到的字段标「待补」，绝不编数；示例参数显著标「示例」；不承诺量化收益。
- 报告内容：不写 prompt、不写教学旁白。
- 页脚写：**实际数据源**（店铺数据 / 卖家精灵 / 1688 接口 / 用户上传报表，没用到的不写）· 数据截止日期 · 生成日期。

## 数据源已知坑（Sorftime / 多宝鱼接口实测）

- `market_research_keyword` 一次传多个关键词会返回空 —— 逐个种子词调用，每次返回该词下约 15 个细分词。
- `market_find_products` 的 `keyword` 会被宽泛拆词匹配（"socket organizer" → 全站 organizer 甚至电源插座）—— 改用 `market_find_node` 拿精确节点 ID + `node_id_path` 检索。
- `category_stats_report` 的值是带前缀整句（如 "Top-80% products median price: 33.99"），先按最后一个冒号切再取数；median_price 可能是 0.00、return_rate 可能是空串。
- 集中度只有 Top3，报告里写明「Top3」，不能简写成「集中度」。占比类参数用 0–1（10% 传 0.1）；ratings_max 是星级，ratings_count_max 是评论条数。
- seller_origin 是中文枚举，中国卖家占比 = (中国 + 中国香港 + 中国台湾) ÷ 非「未知」样本。
- 1688 系列数值参数默认值是 0 而不是「不限」，不需要的条件不要传；`ali1688_product_search` 没有关键词参数，且传 node_id 时 sales_of_30d 恒为 0 —— 节点检索只传 node_id。
- 按 ASIN 拼的 Amazon 图片直链返回占位 GIF，主图只能用 product_detail / find_products 返回的 main_image / imageUrl。
- 大明细（category_report 单次约 75KB）落盘后用脚本批量解析，别塞进上下文。
- product_reviews 最多 100 条、仅近一年。
