# Autoloop 工作台

本机运行的可视化面板（仅监听 127.0.0.1，不对外），数据来自：

- `agent-autoloop status --json` / `runs --json` — 轮次、Token、卡片、规则
- 多宝鱼 MCP（亚马逊店铺数据）— 订单、断货、广告、产品洞察

## 功能

- **今日概览**：今天跑了几轮、Token/花费、谁在线
- **现在**：等人拍板的卡片、正在跑的轮次、最近 20 轮结论
- **规则与定时**：每条规则下次几点跑；一键暂停 / 恢复 / 马上跑一次
- **多宝鱼 · 店铺数据**：订单 / 销售（24h / 7天 / 30天切换）、热销 SKU、断货预警
- **广告分析**：账户连接、同步、健康度、近 7/30 天表现（ACOS/CTR/CPC 等）、预算预警、活动启停/改预算（prepare → 预览 → 确认写入）
- **广告优化方案**：最新推荐批次，勾选标记已处理/忽略
- **店铺优化方案**：待处理问题、USD 余额、未来 12 个月补货预测
- **产品优化方案**：热销 ASIN 的买家反馈主题、差评走势、搜索词漏斗（SQP）、建议动作

## 使用

前置：本机安装了 `agent-autoloop`（`~/.agent-autoloop/`），并配置好多宝鱼 MCP（`~/.workbuddy/mcp.json` 的 `mcpServers.duobaoyu.url`）。

```bash
node server.js            # 或双击 start.cmd，访问 http://127.0.0.1:8765/
node make-snapshot.js     # 生成自包含离线快照 workbench-snapshot.html（不入库）
```

- Windows 下可直接双击 `open.cmd`：服务没起会自动拉起，再打开页面
- 零依赖，Node 18+ 即可运行

## 安全

- 只监听 `127.0.0.1` + `::1` 双回环，远端地址与 Host 头双重校验，伪造 Host 返回 403
- MCP 端点与密钥只留在服务端，页面只显示主机名
- 规则动作只允许 pause / resume / run，规则名必须在 CLI 状态白名单内
- 广告写入只允许活动启停与日预算（$0.5–10000），campaignId 必须在已缓存活动清单里；计划 30 分钟过期
- 命令一律通过 spawn 参数数组执行，不拼 shell 字符串
